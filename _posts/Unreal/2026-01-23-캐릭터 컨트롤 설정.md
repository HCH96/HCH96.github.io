## 언리얼 엔진의 캐릭터 컨트롤 시스템

캐릭터 컨트롤은 단순한 입력 처리를 넘어, 컨트롤러의 목표 회전(ControlRotation)을 폰의 트랜스폼, 카메라 구도, 그리고 무브먼트 컴포넌트의 동작 방식에 맞게 동기화하고 제어하는 핵심 시스템이다.

### 캐릭터 컨트롤의 구성 요소
- **컨트롤러 (Controller)**: 플레이어의 입력을 받아 목표 회전값(`ControlRotation`)을 관리한다.
- **폰 (Pawn)**: 월드에 존재하는 물리적 실체로, 컨트롤러의 명령에 따라 트랜스폼이 결정된다.
- **카메라(Camera)**: 플레이어가 보는 화면의 구도를 결정한다. 주로 1인칭 시점 제어에 사용된다.
- **스프링 암 (Spring Arm)**: 3인칭 시점에서 카메라와 캐릭터 사이의 거리 및 구도를 설정하며, 장애물 감지(Camera 트레이스 채널)를 통해 시야를 확보한다.
- **캐릭터 무브먼트 (Character Movement)**: 다양한 이동 모드(Walking, Falling, None 등)를 제공하며, 실제 이동 속도와 회전 속도를 물리적으로 연산한다.

### 폰과 스프링 암의 컨트롤 옵션
컨트롤러의 ControlRotation 값을 각 컴포넌트가 어떻게 반영하느냐에 따라 조작감이 달라진다.

- **폰의 회전 옵션 (Use Controller Rotation)**: 
    - Yaw/Pitch/Roll을 활성화하면 폰의 회전이 컨트롤 로테이션의 회전값과 바로 동기화된다. 
    - 이 경우 캐릭터는 카메라가 회전하는 즉시 해당 방향을 바라보게 된다.

- **스프링 암의 회전 옵션 (Use Pawn Control Rotation)**: 
    - 부모 컴포넌트의 회전을 따를지, 혹은 컨트롤러의 ControlRotation을 직접 따를지 결정한다. 3인칭 게임에서는 주로 컨트롤러의 회전을 따르도록 설정한다.

### 캐릭터 무브먼트의 제어
이동 상태와 회전 방식에 대한 세밀한 설정이 가능하다.

- **이동 모드 및 수치**:
    - MaxWalkSpeed: 걷기 상태에서의 최대 속도.
    - JumpZVelocity: 점프 시 가해지는 수직 속도.

- **회전 방식의 분리**:
    - Orient Rotation To Movement: 캐릭터가 현재 이동 중인 방향(입력 방향)으로 몸을 돌린다.
    - Use Controller Desired Rotation: ControlRotation을 목표 회전으로 삼고, RotationRate에 설정된 속도로 부드럽게 회전한다.
    - Rotation Rate : 회전 속도를 지정한다.

## 동작 원리와 자연스러운 회전 구현
단순히 값을 대입하면 캐릭터가 순간적으로 방향을 바꾸어 어색해 보일 수 있다. 언리얼에서는 RotationRate를 통해 현재 회전값에서 목표 회전값(DesiredRotation)으로 서서히 보간하며 회전시켜 자연스러운 애니메이션 효과를 연출한다.

## 데이터 에셋(Data Asset)
데이터 에셋은 게임 내에서 사용되는 다양한 데이터를 구조화하여 저장하는 데 사용되는 언리얼 엔진의 기능이다.

- **데이터의 구조화**: 데이터 에셋은 UObject를 상속받아 정의된 클래스에 따라 데이터를 구조화한다. 이를 통해 게임 내의 다양한 데이터를 체계적으로 관리할 수 있다.

- **데이터의 재사용**: 데이터 에셋은 여러 액터에서 공유하여 사용할 수 있어, 데이터의 중복을 방지하고 일관성을 유지하는 데 도움이 된다.

### 컨트롤 모드 전환 (Shoulder / Quarter)
- **숄더뷰(Shoulder View)**: 캐릭터의 이동과 마우스 회전에 따른 시점 변환(Look)이 모두 필요하다.
- **쿼터뷰(Quarter View)**: 마우스 회전 없이 고정된 시점에서의 이동(Move)만 강조하며, 주로 Orient Rotation To Movement 설정을 활용한다.
- **입력 기반 전환**: V 키 입력을 트리거로 하여 열거형(Enum)에 정의된 모드를 토글(Toggle)하고, 해당 모드에 맞는 데이터 애셋을 캐릭터에 즉시 투영한다.

### 책임 분리 및 적용 프로세스
- **ABCharacterBase**: 폰(Pawn)의 공통 속성과 CharacterMovement 관련 물리 수치를 설정한다.
- **ABCharacterPlayer**: 플레이어 전용 속성인 SpringArm 길이, Camera 옵션 및 각 모드에 최적화된 Input Mapping Context를 설정한다.

## 데이터 애셋 생성 및 적용 단계
1. **C++ 클래스 생성**: UPrimaryDataAsset을 상속받아 필요한 멤버 변수(SpringArmLength, bUseControllerRotationYaw 등)를 UPROPERTY로 선언한다.
2. **애셋 생성**: 에디터에서 해당 클래스를 기반으로 Shoulder와 Quarter 두 개의 데이터 애셋을 만든다.
3. **매니저 구현**: TMap<ECharacterControlType, UABCharacterControlData*> 자료구조를 사용하여 타입에 따른 애셋을 관리한다.
4. **함수 오버라이딩**: SetCharacterControlData 함수를 통해 베이스 클래스와 플레이어 클래스에서 각각의 영역에 데이터를 적용한다.

## 실습
### 데이터 구조 정의
캐릭터 컨트롤에 필요한 옵션들을 UPrimaryDataAsset으로 모아 관리한다.

```cpp
UCLASS()
class ARENABATTLE_API UABCharacterControlData : public UPrimaryDataAsset
{
    GENERATED_BODY()
public:
    // Pawn & Movement 관련 설정
    UPROPERTY(EditAnywhere, Category = Pawn)
    uint32 bUseControllerRotationYaw : 1;

    UPROPERTY(EditAnywhere, Category = CharacterMovement)
    uint32 bOrientRotationToMovement : 1;

    // ...

    // SpringArm & Camera 관련 설정
    UPROPERTY(EditAnywhere, Category = SpringArm)
    float TargetArmLength;

    UPROPERTY(EditAnywhere, Category = SpringArm)
    FRotator RelativeRotation;
    
    // ...

    // 입력 매핑 컨텍스트 (Shoulder/Quater 각각 다르게 지정)
    UPROPERTY(EditAnywhere, BlueprintReadOnly, Category = Input)
    TObjectPtr<class UInputMappingContext> InputMappingContext;
};

```


### 베이스 클래스의 데이터 적용
데이터 애셋에 정의된 값을 캐릭터의 실제 컴포넌트에 투영하는 함수를 구현한다.

```cpp
void AABCharacterBase::SetCharacterControlData(const UABCharacterControlData* CharacterControlData)
{
    // 데이터 애셋의 값을 Pawn 속성에 적용
    bUseControllerRotationYaw = CharacterControlData->bUseControllerRotationYaw;

    // 무브먼트 컴포넌트 속성 적용
    GetCharacterMovement()->bOrientRotationToMovement = CharacterControlData->bOrientRotationToMovement;
    GetCharacterMovement()->bUseControllerDesiredRotation = CharacterControlData->bUseControllerDesiredRotation;
    GetCharacterMovement()->RotationRate = CharacterControlData->RotationRate;
}
```

### 시점 전환 및 입력 컨텍스트 교체
플레이어 클래스에서는 뷰 전환 키 입력 시 `SetCharacterControl`을 호출하여 데이터와 입력 시스템을 갱신한다.

```cpp
void AABCharacterPlayer::SetCharacterControl(ECharacterControlType NewCharacterControlType)
{
    UABCharacterControlData* NewCharacterControl = CharacterControlManager[NewCharacterControlType];
    
    // 1. 데이터 적용 (Base 호출 포함)
    SetCharacterControlData(NewCharacterControl);

    // 2. Enhanced Input 매핑 컨텍스트 교체
    APlayerController* PlayerController = CastChecked<APlayerController>(GetController());
    if (UEnhancedInputLocalPlayerSubsystem* Subsystem = ULocalPlayer::GetSubsystem<UEnhancedInputLocalPlayerSubsystem>(PlayerController->GetLocalPlayer()))
    {
        Subsystem->ClearAllMappings();
        if (NewCharacterControl->InputMappingContext)
        {
            Subsystem->AddMappingContext(NewCharacterControl->InputMappingContext, 0);
        }
    }
    CurrentCharacterControlType = NewCharacterControlType;
}
```
