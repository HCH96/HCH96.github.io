[수집합](https://www.acmicpc.net/problem/4373)


## code

```cpp
#include <iostream>
#include <bits/stdc++.h>
#include <sstream>
#include <unordered_set>

using namespace std;

int N;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    while (true)
    {
        cin >> N;
        if (N == 0)
            break;

        int Answer = -1;
        vector<long long> v(N);

        for(int i=0; i<N; ++i)
        {
            cin >> v[i];
        }

        sort(v.begin(), v.end());

        unordered_map<long long,pair<int,int>> um;
        for (int i = 0; i < N; ++i)
        {
            for (int j = i + 1; j < N; ++j)
            {
                um[v[i] + v[j]] = { i,j };
            }
        } 

        for (int i = N - 1; i >= 0; --i)
        {
            long long d = v[i];

            for (int j = 0; j < N ; ++j)
            {
                if (i == j)
                    continue;

                long long Target = d - v[j];

                if (um.find(Target) != um.end())
                {
                    auto [Left, Right] = um[Target];

                    if (Left != i && Left != j && Right != i && Right != j)
                    {
                        Answer = d;
                        break;
                    }
                }
            }
            if (Answer != -1)
                break;
        }

        if (Answer == -1)
        {
            cout << "no solution\n";
        }
        else
        {
            cout << Answer << endl;
        }

    }
    
    return 0;
}

```

## 문제 개요

서로 다른 정수로 이루어진 집합 S가 주어진다.  
이때 서로 다른 네 원소 `a, b, c, d`에 대해 `a + b + c = d` 를 만족하는 `d` 중 **가장 큰 값**을 구하는 문제이다.  
만약 그런 `d`가 존재하지 않으면 `no solution`을 출력한다.

---

## 핵심 아이디어

식을 다음과 같이 변형한다.

a + b + c = d  
→ a + b = d - c

즉,

- `d`를 하나 고정하고
- `c`를 하나 고정했을 때
- `d - c`가 **두 수의 합(a + b)** 으로 만들 수 있으면 된다.

---

## 전체 전략

1. 모든 두 수의 합 `a + b`를 미리 구해둔다. (O(N²))
2. `d`를 **큰 값부터** 하나씩 확인한다.
3. 각 `d`에 대해 모든 `c`를 순회하며 `target = d - c`가 두 수의 합으로 존재하는지 확인한다.
4. 합이 `target`인 두 수의 인덱스와 `d`, `c`의 인덱스가 겹치는 경우를 제외한, 첫 번째로 성립하는 답이 정답이 된다.

---

## 왜 인덱스 충돌을 따로 체크해야 하는가?

이 문제는 **서로 다른 네 원소**를 요구한다.

단순히 `a + b = d - c`라는 값만 맞아도,
실제로는 같은 원소를 두 번 쓰는 조합일 수 있다.

예를 들어:

집합: `{0, 1, 2, 4}`

- `d = 4`
- `c = 2`
- `d - c = 2`
- `2 = 0 + 2`

이 경우 식은 `0 + 2 + 2 = 4`가 되는데, `2`를 두 번 사용하므로 **문제 조건 위반**이다.
따라서 **두 수의 합을 만들 때 사용된 인덱스가** `c`나 `d`와 겹치지 않는지 반드시 확인해야 한다.

따라서 두 수의 합을 만들 때 **합 + 인덱스 쌍**을 함께 저장한다.  
그리고 `d - c`에 해당하는 모든 `(a, b)` 쌍 중에서 `a, b, c, d`의 인덱스가 **모두 서로 다른 경우**가 있는지 확인한다.
