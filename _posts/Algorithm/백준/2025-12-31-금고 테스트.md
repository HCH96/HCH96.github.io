[금고 테스트](https://www.acmicpc.net/problem/2266)

### Code

```cpp
#include <iostream>
#include <bits/stdc++.h>
#include <sstream>
#include <unordered_set>

using namespace std;

int N, K;

int main() {
	ios::sync_with_stdio(false);
	cin.tie(nullptr);

	cin >> N >> K;

	int Answer = -1;

	vector<vector<int>> dp(N + 1, (vector<int>(K + 1, 0)));
	for (int i = 1; i <= N; ++i)
	{
		for (int j = 1; j <= K; ++j)
		{
			dp[i][j] = dp[i - 1][j] + dp[i - 1][j - 1] + 1;

			if (dp[i][j] >= N)
			{
				Answer = i;
				break;
			}
		}

		if (Answer != -1)
		{
			break;
		}
	}

	cout << Answer;

	return 0;
}
```

## 문제 개요

N층짜리 건물과 K개의 금고가 주어졌을 때,  
어떤 임계층 F가 존재하여

- F층 이하에서 금고를 떨어뜨리면 깨지지 않고
- F층 초과에서 떨어뜨리면 금고가 깨진다

고 가정한다.

이때, 금고를 떨어뜨리는 실험을 통해  
임계층 F를 **확실하게 판별하기 위한 최소 낙하 횟수**를 구하는 문제이다.

문제에서 중요한 조건은 다음과 같다.

- 금고는 깨지면 다시 사용할 수 없다
- 금고를 떨어뜨릴 때마다
  - 깨지거나
  - 깨지지 않는
  두 가지 결과 중 하나가 발생한다
- 항상 최악의 경우를 기준으로 최소 횟수를 계산해야 한다


## 문제 접근

### 1. 이진 탐색 기반 접근의 한계

가장 먼저 떠올린 접근은 **이진 탐색**이다.

- 전체 층 범위를 절반씩 줄여가며 탐색
- 금고가 충분하다면 빠르게 범위를 축소 가능
- 최소 시행 횟수를 구하는 문제 구조와도 잘 맞아 보인다

이에 따라 다음과 같은 전략을 가정했다.

- 금고가 남아 있는 동안은 이진 탐색으로 범위를 줄인다
- 금고가 1개 남는 순간, 남은 범위를 선형 탐색으로 확인한다
- 선형 탐색은 범위가 작을수록 빠르므로, 최대한 범위를 줄인 뒤 수행하는 것이 최적이라고 판단했다

하지만 이 접근은 문제의 구조를 정확히 반영하지 못한다.

#### 이진 탐색이 성립하지 않는 이유

이 문제는 일반적인 이진 탐색 문제와 달리 **탐색 방식이 상태에 따라 달라지는 비대칭 구조**를 가진다.

- 금고가 깨지지 않으면, 이후에도 효율적인 탐색이 가능하다
- 금고가 깨지는 순간, 남은 금고 수가 줄어들며
- 특히 금고가 1개가 되면 탐색 방식이 **선형 탐색으로 강제된다**

즉, 탐색 과정 중에

- 이진 탐색 → 선형 탐색으로 **비용 구조가 급격히 변한다**

이로 인해 단순히 **범위를 반으로 줄이는 전략**이 항상 최적이 아니다.

예를 들어 금고가 2개일 때, 중간층에서 던져 금고가 깨지면 남은 절반 범위를 전부 선형 탐색해야 한다.  
이 경우, 범위를 줄였다는 사실 자체가 오히려 전체 비용을 증가시킬 수 있다.

따라서 **이진 탐색을 최대한 수행한 뒤 선형 탐색을 하면 최소가 된다**는 가정은 성립하지 않는다.

### 2. DP

- `E(N, K)` : N층에서 K개의 금고로 임계층 F를 판별하기 위한 최소 낙하 횟수

어떤 층 `x`에서 금고를 떨어뜨릴 경우 두 가지 상황이 발생한다.

- 금고가 깨진 경우  
  → 아래 `x-1`층을 `K-1`개의 금고로 탐색  
  → 비용: `E(x-1, K-1)`

- 금고가 깨지지 않은 경우  
  → 위 `N-x`층을 `K`개의 금고로 탐색  
  → 비용: `E(N-x, K)`

최악의 경우를 기준으로 해야 하므로 x층에서 던졌을 때의 `max`를 취하고, 던지는 층 `x`는 우리가 선택할 수 있으므로 `min`을 취한다. 

```text
E(N, K) = min(1 + max(E(x-1, K-1), E(N-x, K))){1 ≤ x ≤ N}
```

이 점화식은 문제를 정확히 표현하지만, x까지 포함되면서 상태 공간이 커지고 계산량이 많다.

### 3. 문제 정의를 뒤집은 DP 접근

계산량 문제를 해결하기 위해 문제의 질문 자체를 변경

- dp[m][k]
  - 금고를 m번 던질 수 있고
  - k개의 금고가 있을 때
  - 확실하게 판별 가능한 최대 층 수

이 정의를 사용하면 dp[m][K] ≥ N 을 만족하는 가장 작은 m이 정답이 된다.

#### 점화식

dp[m][k] 상태에서 금고를 한 번 던지면 다음 두 경우가 발생한다.

- 금고가 깨진 경우
  - 남은 횟수: m-1
  - 남은 금고: k-1
  - 아래쪽에서 dp[m-1][k-1]층을 확실히 판별 가능
- 금고가 깨지지 않은 경우
  - 남은 횟수: m-1
  - 남은 금고: k
  - 위쪽에서 dp[m-1][k]층을 확실히 판별 가능

또한, 던진 현재 층 1개는 항상 판별된다.

- 점화식
```text
    dp[m][k] = dp[m-1][k-1] + dp[m-1][k] + 1
```

- 알고리즘
    - 1. dp[0][*] = 0으로 초기화한다.
    - 2. m = 1, 2, 3 ... 순서대로 dp를 계산한다.
    - 3. dp[m][K] ≥ N이 되는 순간의 m이 정답이다.
